# UI Kit

Компактные Angular-компоненты на основе Zard UI, адаптированные под Cuteness.
Публичные импорты — только из `@cuteness/ui-kit`. Цвета и радиусы — в `src/styles.css`.

- `button[z-button]`, `a[z-button]`: обычная или прозрачная кнопка, размер обычный или для иконки.
- `z-slider`: один числовой параметр; нативный range, скалярная модель `[(zValue)]`.
- `select[z-select]`: нативный select; формы и числовые значения обслуживает Angular Forms.
- `z-sheet`: меню слева на нативном dialog; `[(zVisible)]`, обязательная подпись `zLabel`.
- `[zTooltip]`: стандартная подсказка браузера через title.
- `z-spinner`: индикатор загрузки.

Ползунок, select и dialog используют клавиатуру и обработку касаний браузера. В dialog браузер управляет модальностью, фокусом и Escape.

Добавляем возможности, только когда они нужны приложению. Здесь нет мультиселекта, сервисного API оверлеев, локалей, кастомных event plugins и определения иконок через MutationObserver.

Исходная библиотека: [Zard UI](https://zardui.com/), [исходники и лицензия MIT](https://github.com/zard-ui/zardui).
