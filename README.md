# Cuteness

Cuteness — авторский проект, посвящённый интерактивной визуализации математических моделей и исследованию алгоритмов в браузере.

Проект объединяет визуализацию множества Мандельброта, сравнение алгоритмов решения задачи коммивояжёра и экспериментальные модули. Реализация охватывает вычислительные методы, графический вывод и пользовательский интерфейс с поддержкой настольных и мобильных устройств.

**[Демонстрация проекта](https://xel4ek.github.io/cuteness/)**

## Множество Мандельброта

**[Открыть визуализацию](https://xel4ek.github.io/cuteness/#/fractal)**

Интерактивная визуализация множества Мандельброта с поддержкой глубокого масштабирования.

- Вычисление изображения на GPU через WebGPU.
- Хранение координат на основе `BigInt` с увеличением точности по мере масштабирования.
- Масштабирование относительно курсора, перемещение и выделение области; поддержка сенсорного управления.
- Преобразование последнего готового кадра во время расчёта нового изображения.
- Настройка предела итераций для изменения детализации границы множества.
- Сохранение точных координат, масштаба и числа итераций в ссылке на выбранную область.

Вычисления основаны на методе возмущений с опорной орбитой. При реализации использован подход из [проекта Bert Baron](https://github.com/bertbaron/mandelbrot).

## Задача коммивояжёра

**[Открыть сравнение алгоритмов](https://xel4ek.github.io/cuteness/#/tsp)**

Поиск кратчайшего замкнутого маршрута, проходящего через каждую вершину графа. На одном графе можно сравнить четыре реализации:

| Алгоритм                     | Метод                                      |
| ---------------------------- | ------------------------------------------ |
| Little на TypeScript         | Точный поиск методом ветвей и границ       |
| Little на Rust / WebAssembly | Точный поиск методом ветвей и границ       |
| Генетический                 | Эволюционная эвристика поиска маршрута     |
| Муравьиный                   | Эвристика с накоплением феромона на рёбрах |

Интерфейс отображает граф, найденный маршрут и результат последнего запуска каждого алгоритма: длину маршрута, время выполнения и объём поиска. Генетический и муравьиный алгоритмы позволяют сопоставить приближённые решения с результатами точного поиска, но не гарантируют оптимальность маршрута.

Граф отображается в 3D с помощью Three.js и 3d-force-graph: стрелки показывают направления дорог, а найденный маршрут выделяется цветом. Сцену можно вращать перетаскиванием и приближать колесом или жестом; кнопка с прицелом вписывает граф в область просмотра.

Граф занимает всё пространство под шапкой. Компактные ползунки, генерация и вписывание графа находятся рядом. Карточки алгоритмов показывают последний результат и содержат остановку и повторный запуск; маршрут виден при наведении или фокусе. Кнопка матрицы показывает таблицу при наведении и скачивает текстовую матрицу с табуляцией между значениями по нажатию. На сенсорном экране нажатие открывает предпросмотр с кнопкой скачивания.

Положение вершин — приблизительная трёхмерная схема по стоимости проезда, а не географическая карта. Для раскладки берётся минимальный вес из существующих направлений каждой пары; отсутствующие рёбра не задают расстояние. Схема и выбранный ракурс сохраняются при сравнении алгоритмов, а исходные направленные веса используются для поиска маршрутов без изменений. Для отображения требуется WebGL 2.

## Экспериментальные модули

- **[Солнечная система](https://xel4ek.github.io/cuteness/#/solar-system)** — модуль на Rust с использованием GPU. Находится в разработке.
- **[OPFS](https://xel4ek.github.io/cuteness/#/opfs)** — эксперимент с файловым хранилищем браузера Origin Private File System.

## Технологии

Интерфейс и прикладная логика реализованы на Angular и TypeScript. Web Workers используются для фоновых вычислений, WebGPU — для вычислений и графического вывода на GPU, Rust и WebAssembly — для отдельных вычислительных модулей.

Код приложения организован в монорепозиторий Nx; Rust-модули объединены в Cargo workspace.
